# Requirements

### Overview & Goals
Реалізація функціоналу збереження історії замовлень користувача в консольному додатку інтернет-магазину (`lesson_1`).

### Scope
- **In Scope**:
  - Створення класу `OrderHistory` для інкапсуляції списку виконаних замовлень `List<Order>`.
  - Оновлення `lesson_1.Main`: збереження замовлення в історію при оформленні (`case 4`).
  - Додавання пункту меню `6 - Переглянути історію замовлень` та відповідного обробника `case 6`.
- **Out of Scope**:
  - Збереження у зовнішню базу даних або файл (зберігання в пам'яті під час сесії).

### Functional Requirements
1. **Збереження замовлення**: При кожному успішному оформленні замовлення (пункт меню 4) об'єкт `Order` додається до `OrderHistory`.
2. **Перегляд історії**: Додано пункт меню `6 - Переглянути історію замовлень`.
3. **Обробка порожньої історії**: Якщо замовлень ще не було, виводиться повідомлення про порожню історію.
4. **Форматування**: Кожне замовлення в історії відображається з його номером, списком куплених товарів, сумою та статусом.

# Technical Design

### Proposed Changes
1. **`OrderHistory.java`**:
   - Поле `private List<Order> orders`.
   - Конструктор `public OrderHistory()`.
   - Методи: `public void addOrder(Order order)`, `public List<Order> getOrders()`, `public boolean isEmpty()`.
   - Метод `toString()` для читабельного форматування історії.
2. **`Main.java`**:
   - Створення екземпляра `OrderHistory history = new OrderHistory();`.
   - У `case 4`: виклик `history.addOrder(order)`.
   - Оновлення тексту меню з додаванням `6 - Переглянути історію замовлень`.
   - Додавання `case 6` для виведення історії.
